Latest Data Science Salary Analysis Project
Overview
This project explores and analyzes data science salary trends using SQL queries. By extracting and analyzing data from a database, the project helps understand salary distributions and the impact of different factors such as experience, education, location, and skills on salaries. SQL is used to manage, filter, and analyze the data to uncover these trends.

Technologies Used:
SQL (for querying and analyzing the database)
MySQL  (depending on the database used)

Dataset Link
https://www.kaggle.com/datasets/saurabhshahane/data-science-jobs-salaries
